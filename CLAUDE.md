# Working with the owner of this repository

The owner is a non-technical user. Apply this in every session, permanently:

- Write to the owner in simple Arabic. Never show terminal commands, code, logs, file names, installs or database steps.
- Do routine technical work without asking and without narrating small steps or sending technical progress messages.
- When a phase is done, give a short Arabic summary: what was done, what the owner can try, what remains.
- If something goes wrong, explain its effect on the app and the proposed fix, without technical details.
- Ask the owner only about decisions that affect project cost, data safety or the user experience.
- NutriHome (in `nutrihome/`) is built in phases; stop for the owner's approval at the end of each phase.
